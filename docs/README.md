# AllFiles documentation

AllFiles 0.1.6 is the public release of the current Rust application. It catalogs file locations and extracted text for local, offline use. It does not store backup copies of the original files.

[Download v0.1.6](https://github.com/vladimirperovic/allfiles/releases/tag/v0.1.6) or open the [browser demo](https://vladimirperovic.github.io/allfiles/). The demo immediately displays a dashboard with fictional data for 1 LTO tape, 3 Blu-ray media and 3 disks. It does not connect to your catalog or read your files.

Historical tags 0.2.0 and 0.3.0 remain unchanged. Their version labels in benchmark results are historical identifiers, not the version of the current public package.
